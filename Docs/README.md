# MinistryTracker Documentation

This project includes planning and reference documents under the `/docs` folder:

- **BRD_v1.md**  
  Business Requirements Document. Defines the app’s scope and key features (Dashboard, Students, Visits, Settings, About, Navigation).

- **MinistryTracker_Kanban.xlsx**  
  Kanban board in Excel format with columns (Backlog, Ready, In Progress, QA, Done). Tracks all user stories for development.

- **architecture.md**  
  Technical reference document. Describes platform, folder structure, and architectural principles.

## How to Use
- Update the **Kanban Excel file** as you move tasks between stages.  
- Revise the **BRD** as requirements change.  
- Expand the **Architecture Reference** as the project grows (e.g., add diagrams, service details).

Keeping these three files in `/docs` ensures the business requirements, tasks, and technical reference stay version-controlled together with the source code.
